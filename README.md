# 3D Print Profit Calculator

A lightweight, mobile-friendly browser calculator for estimating the true cost and selling price of a 3D print.

## MVP

- Material cost with waste/failure allowance
- Electricity cost from print time, power draw and electricity rate
- Printer depreciation per print
- Labour
- Marketplace/payment fee
- Target profit margin
- Break-even price
- Recommended selling price
- Profit per print
- Revenue and profit projection by unit count
- Print/save result

## Run

No build step or dependencies. Open `index.html` in a browser.

## Deployment

The site can be deployed as a static site on GitHub Pages or another static host.
